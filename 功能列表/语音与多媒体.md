# 语音与多媒体

## 能力

- TTS 多供应商、ElevenLabs v3、段落朗读、自动播放、仅引用/仅英文等策略；ElevenLabs v3 支持流式 MP3 输出和音频标签控制。
- ASR 提供商和系统输入法语音通话界面。
- 助手可在启用本地工具后主动邀请当前聊天用户通话；来电支持震动、滑动接听、拒接和 30 秒未接反馈。接听后明确回传 ACTIVE 状态，挂断后更新原工具结果并回传 ENDED 状态，不额外生成一轮消息。
- ElevenLabs v3 通话回复保留英文音频标签供 TTS 解释，聊天和通话 UI 会将标签作为可视化标注；非通话回复不注入该通话标签规则。
- 图片、PDF、DOCX、PPTX、EPUB 等多模态输入；OCR 可使用独立接口。
- 图片生成、文件预览、本地图片持久化和 Markdown/代码/公式渲染。

## 核心入口

- 语音模块：`speech/src/main/java/me/rerere/tts/`、`me/rerere/asr/`
- ElevenLabs TTS：`speech/src/main/java/me/rerere/tts/provider/providers/ElevenLabsTTSProvider.kt`、`speech/src/main/java/me/rerere/tts/provider/TTSProviderSetting.kt`
- 通话 UI：`ui/pages/chat/VoiceCallOverlay.kt`、`ui/pages/chat/Background.kt`
- 来电 UI：`ui/pages/chat/IncomingVoiceCallOverlay.kt`
- 自动朗读：`ui/pages/chat/TTSAutoPlay.kt`
- 文档解析：`document/`
- OCR：`data/ai/transformers/OcrTransformer.kt`、`data/ai/prompts/OcrPrompt.kt`
- 图片生成：`ui/pages/imggen/`、`GenMediaRepository.kt`
- 文件：`data/files/FilesManager.kt`

## 修改提示

- 键盘关闭与挂断是不同生命周期事件，修改通话 Dialog 时不可混用。
- 主动来电复用工具审批状态；接听后以 `VoiceCall` 模式续跑，拒接或超时结果必须返回模型。
- 接听和挂断是同一工具调用的状态更新；挂断不应自动启动新的模型完成回合。
- ElevenLabs v3 的音频标签只在已接通通话中作为模型提示和 TTS 输入保留，普通聊天不应复用通话状态提示。
- 多媒体 URI 写入持久化数据前要复制到应用私有目录。
- OCR/压缩独立 API 配置不能污染普通聊天供应商设置。
