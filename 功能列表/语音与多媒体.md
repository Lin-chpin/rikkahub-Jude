# 语音与多媒体

## 能力

- TTS 多供应商、ElevenLabs v3、MiniMax Speech 2.8、段落朗读、自动播放、仅引用/仅英文等策略；ElevenLabs v3 支持流式 MP3 输出，ElevenLabs v3 与 MiniMax Speech 2.8 共用通话音频标签目录。
- ASR 提供商和系统输入法语音通话界面。
- 助手可在启用本地工具后主动邀请当前聊天用户通话；来电支持震动、滑动接听、拒接和 30 秒未接反馈。接听后明确回传 ACTIVE 状态，挂断后更新原工具结果并回传 ENDED 状态，不额外生成一轮消息。
- 支持音频标签的通话采用两阶段生成：第一次按正常通话规则生成回复；客户端持有原文并按句分段，第二次调用只保留独立标签协议和“为可爱、亲昵、略会撒娇角色指导台词”的声音导演人设，输入只包含带索引的原文分段。二次模型必须调用专用工具从共用标签目录选择稳定 ID，不能返回或改写正文。标签表示可听见的声音事件，不是情绪或语气修饰；客户端将标签放在句首，并将全文一次提交给 TTS 控制器，由其按句分块合成和播放，通话气泡同步逐句显示并在播放结束后退出加载态。ElevenLabs v3 为每段渲染一个方括号标签；MiniMax Speech 2.8 允许选择 `NONE`，其余标签渲染为圆括号，且只使用官方支持的 `laughs`、`chuckle`、`coughs`、`clear-throat`、`groans`、`breath`、`pant`、`inhale`、`exhale`、`gasps`、`sniffs`、`sighs`、`snorts`、`burps`、`lip-smacking`、`humming`、`hissing`、`emm`、`sneezes`。通话 UI 显示最终标签及 fallback 原因用于核验，聊天消息持久化和普通聊天 UI 仍为纯文本。
- 图片、PDF、DOCX、PPTX、EPUB 等多模态输入；OCR 可使用独立接口。
- 图片生成、文件预览、本地图片持久化和 Markdown/代码/公式渲染。

## 修改提示

- 键盘关闭与挂断是不同生命周期事件，修改通话 Dialog 时不可混用。
- 主动来电复用工具审批状态；接听后以 `VoiceCall` 模式续跑，拒接或超时结果必须返回模型。
- 接听和挂断是同一工具调用的状态更新；挂断不应自动启动新的模型完成回合。
- 通话结构化标签只在已接通通话中注入；原始工具参数不进入消息文本，客户端生成的合法标签保存在通用消息元数据中，供 TTS 和通话界面核验使用。继续兼容读取旧的 `elevenLabsV3VoiceCall` 元数据。
- 第二次标注关闭记忆、普通工具、技能、推理和模型流式输出，只临时注入 `select_voice_call_audio_tags` 专用工具。工具参数的 `tagId` 是共用标签目录生成的 JSON Schema 枚举，并再次校验分段数量、索引完整性和标签合法性；模型不能提供正文。供应商格式化在校验后进行：ElevenLabs v3 使用 `[word]`，MiniMax Speech 2.8 使用 `(word)`。
- 二次请求异常、未调用专用工具或工具参数无效时，ElevenLabs v3 使用 `breath` 回退；MiniMax Speech 2.8 使用无标签回退。通话 UI 显示 `request_error`、`missing_tool_call` 或 `invalid_tool_arguments`。
- 普通聊天展示和送模上下文都必须清除已知方括号、圆括号通话标签及标签元数据，避免挂断后的文本聊天继续模仿通话输出。
- 多媒体 URI 写入持久化数据前要复制到应用私有目录。
- OCR/压缩独立 API 配置不能污染普通聊天供应商设置。
