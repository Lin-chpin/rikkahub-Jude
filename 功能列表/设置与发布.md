# 设置与发布

## 能力

- 主题、UI、通知、模型、供应商、搜索、语音、MCP、Web 和文件设置。
- Debug APK 不再在系统状态栏区域绘制全局 `[开发模式]` 提示；设置页由 `developerMode` 控制的开发者入口、开发者页面和路由保持不变。
- 用量提醒与超时锁定：超过设定的每日使用时长后，应用锁和系统锁会显示超限时长，并在次日 00:00 自动解锁。
- GitHub Latest Release 检查、更新卡片和 DownloadManager 下载 APK。
- debug ABI 分包：arm64、x86_64、universal。

- OCR、压缩和二次语音情绪标签均支持「单独使用模型 API」：开关关闭时默认使用聊天模型（模型选择按钮复用标题总结模型样式，默认显示聊天模型、可换模型、清除后回到聊天模型），聊天模型也未配置时直接报错；开启时使用独立的 OpenAI 兼容 API。不新增单独的 Responses API 开关（Responses API 选项保留在独立 API 表单内）。
- 二次语音情绪标签模型默认跟随聊天模型，也可在设置页通过「单独使用模型 API」配置独立 API 与模型；该配置只影响二次标签请求。

## 核心入口

- 设置模型：`data/datastore/PreferencesStore.kt`
- 设置 UI：`ui/pages/setting/`
- 更新检查：`utils/UpdateChecker.kt`
- 更新 UI：`ui/components/ui/UpdateCard.kt`
- 版本：`app/build.gradle.kts`
- 打包：`scripts/build-universal-debug-apk.ps1`

## 发布规则

- 版本判断使用 `versionName`，新 Release 必须高于当前版本。
- Release 资产优先名为 `app-universal-debug.apk`，缺失时才回退 arm64。
- GitHub 更新 API 与下载页面统一使用当前仓库 `Lin-chpin/rikkahub-Jude`，避免依赖旧仓库重定向。
- 默认不构建、不提交、不发布；只有用户明确要求才执行。
- `personal` flavor 的私有功能（`app/src/personal/`、`scripts/personal/`）为本地专属，git 忽略且禁止提交；公开构建只产出 public flavor，不包含心跳相关内容。私有包构建见 [私有心跳.md](私有心跳.md)。
