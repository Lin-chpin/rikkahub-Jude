# 助手与记忆

## 能力

- 助手名称、头像、人设、模型参数、聊天背景、独立语音通话背景、预设消息和快捷消息。
- 助手级/全局长期记忆，近期聊天引用。
- 模式注入、Lorebook、正则输入输出处理、技能、MCP 和本地工具选择。
- 会话可按助手授权覆盖系统提示词和提示词注入。
- 助手默认启用匿名提问箱，可在“助手设置 → Local Tools（本地工具）”中关闭。

## 数据

- 助手配置序列化在 `Settings.assistants`。
- 长期记忆存 Room：`MemoryEntity`/`MemoryDAO`。
- 本地记忆工具创建、修改和删除的记忆统一归属助手 ID；会话记忆/全局记忆开关不影响这类记忆的陈列和适用窗口。
- `MemoryScope` 仍表达其他功能所需的助手、全局和 `conversation` 作用域；旧本地记忆工具写入的 `conversation:<会话 UUID>` 记录在数据库 26→27 迁移时归并到对应助手并去重，全局作用域记录不参与迁移。
- 会话独立提示词随 Conversation 保存。

## 核心入口

- 模型：`data/model/Assistant.kt`
- UI：`ui/pages/assistant/`、`ui/pages/assistant/detail/`；背景选择复用 `ui/pages/chat/Background.kt`
- 记忆：`data/model/MemoryScope.kt`、`data/repository/MemoryRepository.kt`、`data/ai/tools/MemoryTools.kt`
- 技能：`data/files/SkillManager.kt`、`ui/pages/extensions/SkillsPage.kt`

## 记忆作用域变更

- 记忆作用域现支持助手、全局和 `conversation` 三种模式；开启会话记忆后，记录只属于当前聊天窗口。
- 本地记忆工具不再使用会话或全局作用域；其记忆始终在助手设置中陈列，并对该助手的所有聊天窗口生效。

## 修改提示

- 新助手字段必须给默认值并考虑 Settings JSON 兼容。
- `voiceCallBackground` 与 `voiceCallBackgroundOpacity` 是助手级可选配置；未设置时通话界面回退到默认背景。
- 人设相关行为同时检查助手 system prompt 和 conversation system prompt。
- 本地记忆工具的记录范围固定为助手级；`enableMemory` 只控制工具是否注入，不改变已保存记录的作用域。
- 记忆查询、新增、修改和删除都必须传入同一个 `MemoryScope`，禁止仅凭记录 ID 跨作用域修改。
