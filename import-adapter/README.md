# RikkaHub Import Adapter

This is a standalone Android application for converting upstream RikkaHub database backups into the versioned `.rhk` transfer format accepted by RikkaHub.

The adapter runs locally on the phone. It reads the selected backup through Android's document picker, creates a new `.rhk` file, and never opens or writes the RikkaHub app database.

## User flow

1. Install the adapter APK from a GitHub Release.
2. Select the upstream RikkaHub backup.
3. Export the generated `.rhk` file.
4. In RikkaHub, open `Settings > Backup and Restore > Import from other app > Import converted RikkaHub data`.

## Transfer format

The package is a ZIP containing:

- `manifest.json` — format version, source information, counts, and warnings;
- `conversations.json` — normalized conversations and message nodes;
- `diagnostics.json` — source schema and conversion diagnostics.

The App import contract is `rikkahub-transfer` format version `1`. Upstream schema changes should be handled here without changing that contract. Unknown or unreadable rows are reported instead of being silently discarded.

## Local build

The project uses the repository's cached Gradle 9.4.1 and JDK 21. The debug APK is generated by:

```text
gradle -p import-adapter :app:assembleDebug
```

For a GitHub Release, configure a stable Android release keystore in `local.properties` or CI secrets. Do not commit the keystore or `local.properties`; Android updates require all releases to use the same signing key.

The local signing keys are:

```properties
adapter.storeFile=path/to/import-adapter-release.jks
adapter.storePassword=...
adapter.keyAlias=...
adapter.keyPassword=...
```

Build the signed release APK with:

```text
gradle -p import-adapter :app:assembleRelease
```

Attach `import-adapter/app/build/outputs/apk/release/app-release.apk` and its SHA-256 value to a GitHub Release such as `adapter-v1.0.0`. Keep adapter tags separate from the main App tags.
